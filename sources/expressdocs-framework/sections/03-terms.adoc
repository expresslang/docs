[[terms]]
== Terms and definitions

==== EXPRESSdocs project

A directory of source material — EXPRESS schemas, Annotated EXPRESS documents
per ELF 5001, collection manifests, and authoring templates — sufficient for a
conforming implementation to produce published documentation.

==== collection manifest

A data document declaring the documents, schemas, and build directives of an
EXPRESSdocs project. It contains no executable logic.

==== implementation

A processor that consumes an EXPRESSdocs project and produces published
documentation and delivery artifacts as specified by this document.

==== derived data

Content generated by a build from source material, such as extracted concept
datasets or exported schema listings. Derived data is reproducible: it is
never an input to its own production.

==== template

An authorable rendering unit (e.g. a Liquid template) bound to one EXPRESS
construct class, through which an implementation renders that construct.

==== staged build

An implementation strategy that renders disjoint member subsets in separate
executions against a shared store, then composes the site from the store.
